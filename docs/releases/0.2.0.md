**A native Android conversation experience.** Version 0.2.0 replaces the default browser-based phone experience with native Android screens and a direct live connection to Murmur.

## Download and install

Expand **Assets** below. Download **`murmur-companion-0.2.0-debug.zip`** for both matching APKs and the complete installation guide, or download the phone and watch APKs separately.

1. Install `murmur-companion-phone-debug.apk` on your Android 9+ phone.
2. Install `murmur-companion-wear-debug.apk` separately on the paired Wear OS 3+ watch using the included wireless ADB instructions.
3. Open the phone app and connect to your Murmur address. If sign-in is needed, tap the sign-in card, finish in Workspace, then tap **Native app** in its top bar.
4. Choose an agent and open or create a conversation. The watch continues to use its own Watch chat through the phone.

**Upgrading from 0.1.0:** these preview builds use a new debug signing certificate. If Android rejects the upgrade, uninstall the old app on both devices, then install this matching pair. Uninstalling clears local sign-in, settings and drafts; server chats remain. No build tools are needed for the phone APK; the watch needs Android Platform Tools for sideloading.

## What feels different

- Native Chats, Agents and Settings navigation, recycled conversation lists, and cached screens.
- Native conversation history, a multiline composer, selectable text, basic Markdown, copy and links.
- Replies stream directly over a persistent WebSocket, without loading a webpage.
- Start and rename chats, stop an active response, and dictate into a draft before sending.
- Drafts survive navigation and Activity recreation; an uncertain send is never automatically replayed.
- Native approval cards with full action details and confirmation for Allow once; native clarification forms.
- Watch handoff reminders target the selected agent's Watch chat on the phone.
- Connections stay in memory across rotation and close after 20 seconds in the background; returning syncs from the server.

## Scope of this preview

The **Full Murmur workspace** remains available for sign-in, groups, models, memories, routines, integrations, attachments and rich tool content. Those advanced screens still use Murmur's web interface. This is not a claim of complete native desktop feature parity.

Automated contract and Android runtime tests cover streaming, duplicate/gap handling, explicit approval responses, native chat with no WebView, a single prompt submission and draft preservation across Activity recreation. Both APKs and lint pass. Layouts are verified with native Android runtime renders. Actual phone/Pixel Watch, Tailscale handover and live Murmur checks remain outstanding.

Assets include both debug-signed APKs, a combined bundle, `INSTALL.md`, `SHA256SUMS` and the public signing fingerprint. GitHub also provides source ZIP/tarball downloads.
