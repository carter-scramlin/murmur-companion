The first installable preview of **Murmur Companion for Android and Wear OS**. Independent community software for Murmur by Umbrel.

## Download

Open **Assets** below and download:

- **`murmur-companion-0.1.0-debug.zip`** — recommended: both matching APKs, full installation instructions, Tailscale setup, and checksums.
- **`murmur-companion-phone-debug.apk`** — install on your Android phone (Android 9+).
- **`murmur-companion-wear-debug.apk`** — install separately on your paired Wear OS watch (Wear OS 3+, including Pixel Watch).
- **`INSTALL.md`** — phone and watch installation instructions, including wireless ADB commands.
- **`SHA256SUMS`** and **`SIGNING-CERTIFICATE.txt`** — file hashes and the public signing certificate fingerprint.

GitHub also provides the source ZIP and tarball below. No Android Studio or app build is needed to install the APKs.

## Get started

1. Install the phone APK, open it, enter your existing Murmur server address and sign in.
2. Install the watch APK using wireless ADB: enable Developer options and Wireless debugging on the watch, run `adb pair WATCH_IP:PAIRING_PORT`, then `adb connect WATCH_IP:CONNECTION_PORT` and `adb -s WATCH_IP:CONNECTION_PORT install -r murmur-companion-wear-debug.apk`. Pairing and connection ports differ; see the full guide.
3. Open the watch app, choose an agent, speak or type a message, review it and send.

The phone and watch must be paired, have Google Play services, and use both APKs from this release. The watch reaches Murmur through the phone. For remote access, connect your phone and server to Tailscale and use your private HTTPS server address.

## Included

- Your server's Murmur interface on Android, with saved sign-in, file picking, direct downloads, microphone permissions and connection diagnostics.
- A native round-screen Wear OS interface with agent selection, voice/keyboard input, review before sending, replies and crown scrolling.
- Private connectivity through the Android Tailscale app; no separate watch VPN required.

## Preview status

These are **debug-signed preview APKs**, not a Play Store or stable production release. If Android rejects an update from an earlier local/website build because its signing key differs, uninstall the old app on both devices before installing this matching pair. Uninstalling clears local sign-in and connection settings, so sign in again afterward.

Both apps pass automated tests and Android lint. Physical Pixel Watch and live Murmur validation remain outstanding. Full desktop/browser feature parity is incomplete: background Web Push is not implemented; some embedded OAuth, blob exports and browser media features require further work. [Feature matrix](https://github.com/carter-scramlin/murmur-companion/blob/v0.1.0/docs/FEATURES.md).
