**Murmur's characters, now at home in the native app.** This is an optimized beta candidate for limited testing.

## Download

Expand **Assets** and choose **`murmur-companion-0.3.0-beta.1-candidate.zip`** for both matching APKs, installation instructions, the beta guide and checksums. Individual phone and watch candidate APKs are also available.

These are **optimized, non-debuggable release builds signed with a temporary preview key**. Permanent distribution signing and real phone/Pixel Watch validation remain gates before a broad beta. See the [beta readiness record](https://github.com/carter-scramlin/murmur-companion/blob/v0.3.0-beta.1/docs/BETA.md).

## New in this candidate

- Native Murmur Buddy characters in agent lists, chat headers, messages, activity cards and the watch's selected-agent screen. Characters follow the agent's colour metadata and have deterministic shapes and expressions.
- Clear Thinking, Working, Replying and Needs you states, with a persistent activity card, elapsed time, human-readable tool activity and Stop.
- A small live-work row keeps progress visible at the end of the conversation; cached chats receive completion events after you leave them.
- Reduced-motion preference and respect for Android animation settings/battery saver. Watch characters remain static.
- Read-only automatic reconnects, capped to three attempts, without repeating a prompt.
- Back navigation remains responsive during a slow resume. Late responses no longer reopen an old screen.
- Scoped drafts save after a short debounce; history and cache sizes are bounded.
- Native feedback sharing excludes server addresses, credentials and chats. A GitHub beta feedback template is included.
- R8 and resource shrinking enabled for release builds.

## Install and test

1. Install `murmur-companion-phone-candidate.apk` on your Android 9+ phone.
2. Install `murmur-companion-wear-candidate.apk` separately on your paired Wear OS 3+ watch using the included wireless ADB guide.
3. Open the phone app, connect to Murmur, finish sign-in if needed, then return to Native app.
4. Choose an agent and try a conversation. Check its character, working states, Stop, approvals, drafts and watch handoff.

Updating from a prior preview key may require uninstalling both old apps first. This clears local sign-in, settings and drafts; server chats remain. Keep both APKs from this exact release together.

Groups, models, memories, routines, integrations, attachments and rich tool content remain in the explicit Full Murmur workspace. Physical-device, live-server and Tailscale handover checks are outstanding. This candidate does not claim complete native desktop parity or readiness for broad distribution.
