# 0.3.0-beta.2 — install fix and a more functional native beta

**Phone: download `murmur-companion-phone-install.apk`.** The watch file belongs on the watch. Expand Assets below; no build tools are needed for the phone.

## Fixed installation conflict

Earlier previews used disposable signing keys under the same package name. Android correctly refused to update an installed copy signed with a different key. This beta uses **`dev.murmur.companion.beta`**, appears as **Murmur Beta**, and installs alongside the old **Murmur Companion**. You do not need to uninstall the old app. Sign in again in the new app; server conversations remain on Murmur. Private app data cannot be migrated across differently signed apps.

All four APKs share a new **persistent private beta certificate**, pinned in the repository. Future beta updates must retain it; the packaging process refuses a replacement key. The private key stays on the signing host and is never a public asset. Phone and watch must both use this beta pair.

## Added native functionality

- Murmur password sign-in, reusing the app's origin-scoped cookie store. Umbrel gateway sign-in remains available in Workspace.
- Photos and files from Android's picker, streamed uploads to the selected agent, and attachment status in the composer. Photos up to 25 MB; other files up to 100 MB.
- Pin, unpin, archive, restore and delete conversations, with revision checks on edits and a deletion confirmation. Archived history and older conversation pages are available natively.
- A paged full-history reader; recent list pagination; native sharing/export of the shown messages and Android text-to-speech.
- Native model/provider selection, per-conversation thinking level, and agent creation/personality editing.
- Tool summaries, updating plans, helper progress and helper completion in the native transcript.
- System/light/dark appearance; bounded offline reading of up to ten opened conversations, with an opt-out that deletes saved copies. Drafts remain separate.
- **Notify when this reply finishes**: explicit, visible, read-only monitoring of one active chat for up to 30 minutes. Stop it from the notification. Network loss is reported without resending anything. Notification delivery depends on Android background/network policy; this is not general Web Push.
- Stop a reply directly from the watch; more accurate busy state and fewer duplicated completed replies.

## Which file to install

| Asset | Purpose |
|---|---|
| `murmur-companion-phone-install.apk` | Recommended phone install; optimized, non-debuggable |
| `murmur-companion-wear-install.apk` | Recommended paired watch install |
| `murmur-companion-phone-debug.apk` | Installable phone build with Android debugging enabled |
| `murmur-companion-wear-debug.apk` | Matching debug watch build |
| `murmur-companion-0.3.0-beta.2-install.zip` | Recommended install pair, guides and checksums |
| `SHA256SUMS`, `SIGNING-CERTIFICATE.txt` | Public integrity and certificate verification |

Install and debug builds use the same beta ID/certificate and replace one another. Locally built or CI verification APKs can use another key; those are not update-compatible with these public downloads. Use release assets for normal updates.

## Remaining limits and validation

This is a community beta, independent of Umbrel. Groups, memories, routines/goals, integrations and interactive browser tools still use Full Murmur workspace. Native tool output is bounded text, not every desktop visualization. OAuth provider restrictions and server-specific setup cannot be bypassed by the client. The watch requires its paired phone; tiles/complications are not implemented. General background Web Push is not implemented; follow a running reply explicitly for notifications.

Automated contract, API, offline-cache and Android UI checks, lint, optimized builds, matching signatures and APK manifests are checked before publication. Physical phone/Pixel Watch installation, a live Murmur server and Tailscale transitions still require device validation. See [the installation guide](https://github.com/carter-scramlin/murmur-companion/blob/main/docs/INSTALL.md) and [feature matrix](https://github.com/carter-scramlin/murmur-companion/blob/main/docs/FEATURES.md).
